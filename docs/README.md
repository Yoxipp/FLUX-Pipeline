# FLUX documentation

| Folder | Read it for |
|---|---|
| `../backend/resources/manual/FLUX_Manuel.html` | The manual (French): artist guide (part A) and technical guide (part B). |
| `notes/` | Living project memory: `PROJECT_CONTEXT.md` (architecture), `CURRENT_STATE.md` (what works, bugs, debt), `NEXT_STEPS.md` (roadmap), `PROMPT_*.md` (open work briefs). |
| `decisions/` | Architecture Decision Records, `0001` to `NNNN`. Start with `README.md`. |
| `architecture/` | Studies: stack and storage (`ARCHITECTURE_ANALYSIS`, `LOCAL_NETWORK_WEB`), pipeline logic (`PIPE_LOGIC`), USD (`USD_STRATEGY`, `USD_ASSEMBLER_V2`, `USD_PIPELINE_REFERENCE`, `PRISM_USD_STUDY`). |
| `flows/` | User doc of the Flows editor (French): overview, available vs coming, node index. `03_INDEX_NODES.md` is bundled in the app and shown by the (i) button of each node. |
| `development/` | `BUILD.md`: dev launch, installer build, versioning, packaging errors. |
| `audit/` | Repository, security and cleanup audit of 2026-09-16. |
| `history/` | `HISTORY_ANALYSIS.md`: old prompts against the code, section 4 lists what must not be redone. |
| `archive/` | Old notes kept for history (`legacy/` = former root `old/`). Never a current spec. |
| `CROSS_PLATFORM/` | Dual-boot design notes, unrelated to the FLUX code (Windows only, ADR 0013). |

Root files: `README.md` (overview, quick start), `CONTRIBUTING.md` (rules), `STRUCTURE.md` (tree and build-sensitive
paths), `NOTES.md` (local tool instructions).
