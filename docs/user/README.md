# User documentation

> **Work in progress, not a finished product.** FLUX is a student project under active development and testing.
> Features change often, some are experimental or only partly tested, and file and data formats can change between
> versions. Do not rely on it for a production you cannot afford to lose: keep backups of your projects.
> Bug reports and feedback are welcome.

| Guide | Where |
|---|---|
| FLUX manual (French): artist guide and technical guide | In the app, **Settings > Doc**. Source: [`backend/resources/manual/FLUX_Manuel.html`](../../backend/resources/manual/FLUX_Manuel.html). FLUX copies it into `FLUX_DOC/` in your workspace at every start, so it can be opened without the app. |
| Flows editor (French): what a flow is, what works today, every node | In the app, **Settings > Doc > Flows**. Source: [flows/](flows/README.md). The (i) button of each node shows its section of [03_INDEX_NODES.md](flows/03_INDEX_NODES.md). |
