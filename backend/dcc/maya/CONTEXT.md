# CONTEXT - `backend/dcc/maya/`

> Reecrit court le 2026-09-16 (V7-05). Ancienne fiche detaillee (mai 2026, en partie perimee) : `docs/archive/context_md_2026-05/backend__dcc__maya.md`.

`maya_connection.py` (client commandPort `127.0.0.1:7001..7008` ; le port est ouvert par le bloc userSetup de `autostart.py`, S3), `port_guard.py` (Windows), `maya_export*.py`, `maya_import.py`, `maya_publish.py`, `maya_shelf.py`, `maya_usd_light_export.py` (export USD leger ; avec `options.preset` il delegue a `maya_usd_presets.py` : model / rig / anim, ADR 0034), `maya_usd_preview.py` (listing de ce que chaque preset exporterait, `GET /dcc/maya/usd-preview`), `maya_bonecapture.py`, `import_prep.py` (cote backend : chemin ASCII, USD aplati pour mayaUsd, appel JSON de `maya_update` ; sorti de `routers/dcc.py` en V9-08), `maya_update.py` (X4 : tag `flux_project` / `flux_source` / `flux_stamp` / `flux_mode` pose par `run_import` sur les nodes racine d'un import FLUX, `run_list` / `run_replace` pilotes par `POST /dcc/maya/update-imports`, bouton shelf "MAJ" = `update_imports()` dans un thread car le hub rappelle Maya par le commandPort), `maya_rigs.py` (ADR 0023 : boutons shelf "CAM" = `create_camera_rig()` Root > Pan > Tilt > Cam 35 mm 36x24, "LIGHT" = `create_light_rig()` key / fill / rim directionnelles + dome `aiSkyDomeLight` si mtoa charge sinon ambient, un undo chacun, attribut `flux_rig`), `maya_layout.py` (placements `|<ASM>|<CLASS>|<INSTANCE>` pour le publish du layout d'assembly, enveloppe JSON), `autostart.py` (userSetup).

`startup/flux_bridge.py` (ancien pont qui lisait `install_path.txt`) archive dans `old/backend/dcc/maya/startup/` le 2026-09-18 : le bloc userSetup d'`autostart.py` ouvre le port directement et remplace l'ancien bloc `flux_bridge`.

`maya_keys.py` (U1, 2026-09-24) : plage de l'export anime = premiere / derniere cle (selection + hierarchie, ou scene ; cles pilotees `animCurveU*` ignorees), sinon la timeline. `GET /dcc/maya/anim-range?scope=` via `import_prep.call_maya_update(..., module="maya_keys")`. Houdini : `GET /dcc/houdini/anim-range` = playbar. Le Publisher remplit Start / End a l'activation d'ANIMATION (bouton "Cles" pour relire).

`maya_instances.py` (U2, 2026-09-24) : instances d'un perso dans la scene (noeuds racine / namespaces commencant par NAME, ou imports FLUX de NAME via `flux_source`), numero lu dans le nom (`DINGO_02`, `DINGO2`) sinon premier libre. `GET /dcc/maya/character-instances?name=`. Le Publisher (shot, USD leger) les liste des que le perso est choisi, toutes cochees ; une anim publiee par instance cochee (`SEQ_SHOT_ANIM_DINGO` pour 01, `..._DINGO_02` ensuite), exportee depuis les meshes sous le noeud (`run_light_export(root=...)`).
